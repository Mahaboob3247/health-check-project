# Linux Server Health Check Script

## Overview

This is a beginner-friendly Python automation project that performs basic Linux server health checks.

The script automates common monitoring tasks such as:

- Server Uptime Check
- CPU Usage Check
- Memory Usage Check
- Disk Usage Check
- Top 5 Memory Consuming Processes
- Logging to File
- Disk Usage Warning Alert

## Technologies Used

- Python 3
- Linux
- subprocess module
- logging module
- shutil module

## How to Run

```bash
python3 health_check.py
